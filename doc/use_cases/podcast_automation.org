A download that stops halfway should not leave anything in my collection, so
let's write the episode in a temporary place and move it in when it is done.

#+NAME: get_body
#+BEGIN_SRC python :results none :exports code
from pathlib import Path

from clk.lib import createfile, makedirs, move, tempdir


@podcast.command()
@argument('episode', help='The episode to download')
def get(episode):
    'Download an episode'
    collection = Path('music')
    with tempdir() as workspace:
        downloading = Path(workspace) / episode
        createfile(downloading, 'some audio\n')
        makedirs(collection)
        move(downloading, collection / episode)
    createfile(collection / 'fetched.txt', f'{episode}\n', append=True)
#+END_SRC

"

* the state of an episode, shared by several commands
  :PROPERTIES:
  :CUSTOM_ID: 6cf69e7a-e155-41dc-896f-a1ed940d42cd
  :END:

An episode comes in ~todo~. It goes to ~to-process~ to have its audio extracted,
then to ~next~ to wait, then to ~ready~ when it moves to my phone, and to ~done~
once I have listened to it. Several commands take that state, some of them bash
scripts. I write the list once in python, beside the rest of my podcast code.

#+NAME: podcastlib
#+BEGIN_SRC python :results none :exports code
from clk.types import Suggestion

STATES = ["todo", "to-process", "next", "ready", "done"]

stateType = Suggestion(STATES)
#+END_SRC

#+NAME: install_podcastlib
#+BEGIN_SRC bash :results none :exports code :session c8fcfc53-6d2a-4b9c-a836-c303933b6563 :noweb yes
mkdir -p lib
cat<<'EOF' > lib/podcastlib.py
<<podcastlib>>
EOF
export PYTHONPATH="$(pwd)/lib"
#+END_SRC
