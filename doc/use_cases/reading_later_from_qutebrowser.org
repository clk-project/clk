* keeping a page for later
  :PROPERTIES:
  :CUSTOM_ID: keeping-a-page-for-later
  :END:

I read with qutebrowser, and I often stumble upon a page I have no time for. I
already keep them with a clk command.

#+NAME: read_later_body
#+BEGIN_SRC python :results none :exports code
@command()
@argument('url', help='The page to read later')
def read_later(url):
    'Keep a page to read it later'
    print(f'I will read {url} later')
#+END_SRC

#+NAME: read_later

"

* a key in qutebrowser
  :PROPERTIES:
  :CUSTOM_ID: a-key-in-qutebrowser
  :END:

I want a key that does it on the page I am reading. qutebrowser runs userscripts
and gives them the url in ~QUTE_URL~, so mine only calls clk.

#+NAME: userscript
#+BEGIN_SRC bash :results none :exports code
#!/usr/bin/env bash
clk read-later "${QUTE_URL}"
#+END_SRC

I bind it in my config.py.

#+BEGIN_SRC python :results none :exports code
config.bind('<Space>r', 'spawn --userscript read-later')
#+END_SRC

qutebrowser is a python program, and its userscripts get the PYTHONPATH it runs
with. Mine comes with a click of its own, one clk cannot work with.

#+NAME: fake_qutebrowser
#+BEGIN_SRC bash :results none :exports none :session 3ce220fd-c143-4223-aeac-a62212fd8e99
mkdir -p "${TMP}/qutebrowser/lib/click" "${TMP}/qutebrowser/userscripts"
echo 'raise ImportError("clk cannot work with the click of qutebrowser")' > "${TMP}/qutebrowser/lib/click/__init__.py"
# what qutebrowser does when I press the key
press_the_key () {
    (
        export PYTHONPATH="${TMP}/qutebrowser/lib"
        export QUTE_URL="https://clk-project.org/"
        . "${TMP}/qutebrowser/userscripts/read-later"
    )
}
#+END_SRC

#+NAME: install_userscript
#+BEGIN_SRC bash :results none :exports none :session 3ce220fd-c143-4223-aeac-a62212fd8e99 :noweb yes
cat <<"EOF" > "${TMP}/qutebrowser/userscripts/read-later"
<<userscript>>
EOF
#+END_SRC

I press the key, and clk does not even start.

#+NAME: press_the_key
#+BEGIN_SRC bash :results verbatim :exports results :session 3ce220fd-c143-4223-aeac-a62212fd8e99 :cache yes
press_the_key 2>&1 | tail -1

* letting clk use its own libraries
  :PROPERTIES:
  :CUSTOM_ID: letting-clk-use-its-own-libraries
  :END:

With ~CLK_FORCE_DEPS~ set, clk puts what PYTHONPATH says after its own
libraries. It takes its own click, and still finds the rest of PYTHONPATH.

#+NAME: userscript_forcing_deps
#+BEGIN_SRC bash :results none :exports code
#!/usr/bin/env bash
export CLK_FORCE_DEPS=1
clk read-later "${QUTE_URL}"
#+END_SRC

#+NAME: install_userscript_forcing_deps
#+BEGIN_SRC bash :results none :exports none :session 3ce220fd-c143-4223-aeac-a62212fd8e99 :noweb yes
cat <<"EOF" > "${TMP}/qutebrowser/userscripts/read-later"
<<userscript_forcing_deps>>
EOF
#+END_SRC
